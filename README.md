# Weather App (CLI)

A simple command-line weather application built with Python. It allows users to check the current weather for any city.

## Features
- Search weather by city name
- Displays temperature
- Shows weather conditions
- Easy to use

## Technologies Used
- Python
- Requests API

## How to Run
1. Install Python.
2. Install the required package:
   ```bash
   pip install requests
   ```
3. Run the program:
   ```bash
   python weather_app.py
   ```
4. Enter a city name to view the weather.
